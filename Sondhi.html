তৎসম শব্দের স্বরসন্ধি (১৩টি নিয়ম)
১
আ-কার "া" থাকলে বিচ্ছেদে অ/আ + অ/আ হয়
অন্যান্য = অন্য + অন্য
ছাত্রাবাস = ছাত্র + আবাস
২
এ-কার "ে" থাকলে বিচ্ছেদে অ/আ + ই/ঈ হয়
💡 খাতার স্পেশাল টেকনিক:
ঈক্ষা, ঈপ্সা, ঈশ – এই শব্দগুলোতে সবসময় দীর্ঘ-ঈ "ঈ" ব্যবহার করবা।
অপেক্ষা = অপ + ঈক্ষা
নির্মলেন্দু = নির্মল + ইন্দু
মহেশ = মহা + ঈশ
৩-৫
ঐ-কার, ও-কার, ঔ-কার এর নিয়ম
ঐ (ৈ) = অ/আ + এ/ঐ: মতৈক্য = মত + ঐক্য
ও (ো) = অ/আ + উ/ঊ: দুর্গোৎসব = দুর্গা + উৎসব
ঔ (ৌ) = অ/আ + ও/ঔ: মহৌষধ = মহা + ঔষধ
৬-৯
রেফ, ঈ-কার, য-ফলা এবং র্য এর নিয়ম
রেফ (র্) = অ/আ + ঋ: ক্ষুধার্ত = ক্ষুধা + ঋত
ঈ-কার (ী) = ই/ঈ + ই/ঈ: অতীত = অতি + ইত
য-ফলা (্য) = ই/ঈ + অন্য স্বর: অত্যন্ত = অতি + অন্ত
র্য = পরি + অ/আ/উ: উপর্যুক্ত = উপরি + উক্ত

শব্দের মাঝখানে (ঃ), (ো), (রেফ), (র) অথবা যুক্তবর্ণ হিসেবে শ, স, ষ থাকলে চোখ বন্ধ করে বুঝবা এটা বিসর্গ সন্ধি।

তিরস্কার = তিরঃ + কার (স -> ঃ)
